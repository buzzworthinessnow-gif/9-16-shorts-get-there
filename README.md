# How Did We Get Here? — 9:16 YouTube Shorts

A dedicated **vertical 9:16, under-60-second** adaptation of the long-form [Stickman How Did We Get Here?](https://github.com/buzzworthinessnow-gif/Stickman-how-get-here) historical video workflow.

## Shorts defaults

- **Length:** strictly under 60 seconds, aiming for **50–55 seconds**.
- **Format:** portrait **9:16**, composed for mobile from the beginning.
- **Hook:** first **1–3 seconds** capture curiosity; no long opening.
- **Story:** 2–4 verified milestones showing cause and effect, then a clear modern-day payoff.
- **Engagement:** brief subscribe + future-topic comment invitation at the end; no midpoint interruption.
- **Visuals:** expressive stickmen with subtle era-appropriate hats, shirts, jackets, trousers or shorts, and shoes; richly detailed historical illustrated environments.

**Audio:** One narrator only. Stickman characters stay silent, and generated scene audio is muted or disabled where supported. See the [narrator-only audio policy](NARRATOR_ONLY_AUDIO_POLICY.md) for exact prompts and mixing checks.

## How to use

Open the system prompt in a browser-capable ChatGPT Work session or another supported agent with access to VideoExpress, and supply a topic, such as “How did we get here? The car — make a YouTube Short.” The workflow plans, researches, generates, assembles, and checks the final runtime where the tools and account permit. If production access is unavailable, it produces a clearly labeled script and prompt package instead.
